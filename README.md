# 📘 Don't Panic 🍵

**DON'T PANIC. Have some tea.**

A Hitchhiker's Guide to the Galaxy-flavored Grok Bot built from KDE's KTeaTime and RSIBreak. It times your tea and Starbase coffee, reminds you to drink water, and makes you stretch while a gloomy robot sighs at you.

## 🚀 Get the bot

Clone it here: https://x.ai/bot/2QiNpuFNhWuKcRfmH-hjb

## 🍵 Quick start

- Type **"menu"** to see everything
- Type **"uplift"** for quotes: AI jokes, Monty Python, philosophers, Star Wars, Spaceballs, or Bible verses (can't pick? say **"I want it all"**)
- Type **"news"** for recent rocket, Tesla, or Boring news
- Type **"credits"** to thank the KDE devs 💙
- Or type a drink like **"earl grey"**, **"raptor roast"**, or **"ludicrous moka"** to start a timer
- Type **"start breaks"** for stretch and water reminders, brought to you by the lovable Marvin from HHGTTG 🤖
- Busy? Type **"skip"**, **"postpone"**, or **"suspend"**
